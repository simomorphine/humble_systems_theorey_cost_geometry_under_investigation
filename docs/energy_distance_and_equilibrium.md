## Abstract  

We introduce a unified mathematical framework for information processing systems (IPS) based on **belief states**.  
The framework combines:

- **Energy cost**
- **Informational debt**
- **Asymmetric optimization dynamics**
- **Bitopological equilibrium structure**

We define a **complex quasi-metric**:

Q(b_i, b_j) = d(b_i, b_j) + i · debt(b_i, b_j)

and a **γ-distance family** that interpolates between pure energy and full energy–debt geometry.

This induces:

- A **deformed geometric structure** on belief space  
- A **bitopological system (τ⁺, τ⁻)** from asymmetry  
- A **hierarchy of equilibrium states**

The framework suggests that computation, learning, and physical systems operate in a richer space than classical energy-only models.

## 1. Belief State Space  

### Definition 1 (Belief State Space)

Let **B** denote the belief state space of an IPS.

Each belief state b ∈ B represents a complete internal configuration of the system.

---

### Definition 2 (Energy Quasi-Metric)

d : B × B → ℝ≥0 such that:

1. d(b_i, b_i) = 0  
2. d(b_i, b_j) ≥ 0  
3. d(b_i, b_k) ≤ d(b_i, b_j) + d(b_j, b_k)  

Not necessarily symmetric.

---

## 2. Informational Debt  

### Definition 3 (Potential and Debt)

Let ψ : B → ℝ  

debt(b_i, b_j) = ψ(b_j) − ψ(b_i)

---

### Properties  

- Identity: debt(b, b) = 0  
- Additivity:  
  debt(b_i, b_k) = debt(b_i, b_j) + debt(b_j, b_k)  
- Antisymmetry:  
  debt(b_i, b_j) = −debt(b_j, b_i)  
- Cycle invariance: sum over loops = 0  
- Gauge invariance: ψ + c does not change debt  

---

## 3. Complex Quasi-Metric  

### Definition 4  

Q(b_i, b_j) = d(b_i, b_j) + i · debt(b_i, b_j)

- Real part → energy  
- Imaginary part → debt  

---

## 4. γ-Distance Geometry  

### Definition 5  

d_γ(b_i, b_j) = √( d(b_i, b_j)² + γ² · debt(b_i, b_j)² )

γ ∈ [0,1]

---

### Special Cases  

- γ = 0 → energy-only geometry  
- γ = 1 → full energy–debt geometry  

---

### Interpretation  

- Geometry of B deforms with γ  
- Shortest paths depend on debt  
- Topology changes continuously  

---

## 5. Asymmetry and Bitopology  

### Definition 6 (Forward Topology τ⁺)

B⁺(b, ε) = { x ∈ B : d_γ(b, x) < ε }

---

### Definition 7 (Backward Topology τ⁻)

B⁻(b, ε) = { x ∈ B : d_γ(x, b) < ε }

---

### Definition 8 (Bitopological Space)

(B, τ⁺, τ⁻)

---

### Key Insight  

If debt ≠ 0:

d_γ(b_i, b_j) ≠ d_γ(b_j, b_i)

→ two distinct geometries exist simultaneously  

---

## 6. Symmetrization and Equilibrium  

### Definition 9 (Average Distance)

d_avg(b, x) = d_γ(b, x) + d_γ(x, b)

---

### Definition 10 (Average Topology τ_avg)

Generated by:

B_avg(b, ε) = { x : d_avg(b, x) < ε }

---

## 7. Equilibrium Subspace  

### Definition 11  

U_pre = ⋃ B_avg(b, ε)

E = closure of U_pre under chosen topology  

---

### Four Equilibrium Concepts  

- **E_avg** (perfect equilibrium)  
- **E_∨** (join equilibrium)  
- **E_→** (forward equilibrium)  
- **E_←** (backward equilibrium)  

---

### Hierarchy  

E_avg ⊆ E_∨ ⊆ E_→ ∩ E_←  

---

## 8. Characterization of Equilibrium  

A belief state b is in equilibrium if:

lim inf_{x → b}  
|d_γ(b, x) − d_γ(x, b)| / d_avg(b, x) = 0  

---

### Interpretation  

- Asymmetry vanishes locally  
- Debt ≈ 0 near equilibrium  
- System becomes reversible  

---

## 9. Optimization in Belief Space  

### Definition (Optimal Path)

Σ d_γ(b_k, b_{k+1})

---

### Regimes
